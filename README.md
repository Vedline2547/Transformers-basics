# 📖 Overview

This project introduces the fundamentals of **Transformer architectures** and demonstrates how to work with **pretrained BERT models** using both **PyTorch** and **TensorFlow**. It also includes the implementation and visualization of a simplified **Transformer Encoder Block** built with TensorFlow/Keras.

The project is intended for beginners who want to understand how Transformer models process text and how to use Hugging Face's **Transformers** library for Natural Language Processing (NLP).

---

# 🎯 Objectives

* Understand the architecture of Transformer models.
* Visualize a simplified Transformer Encoder Block.
* Set up an NLP environment using the Hugging Face Transformers library.
* Load pretrained BERT models.
* Tokenize text using a BERT tokenizer.
* Perform inference using both PyTorch and TensorFlow implementations.
* Explore the hidden representations generated by BERT.

# 🧠 Project Components

## 1. Transformer Encoder Block

This module builds a simplified Transformer Encoder consisting of:

* Multi-Head Self-Attention
* Residual Connections
* Layer Normalization
* Feed-Forward Neural Network

The architecture is visualized and saved as:

```text
transformer_encoder.png
```

---

## 2. BERT using PyTorch

This implementation demonstrates how to:

* Load the pretrained **bert-base-uncased** model
* Tokenize input text
* Convert text into tensors
* Pass the tensors through BERT
* Obtain contextual embeddings

Example sentence:

```text
Transformers are powerful models for NLP Tasks
```

Output:

```text
Hidden States Shape:
(batch_size, sequence_length, hidden_size)
```

---

## 3. BERT using TensorFlow

The TensorFlow version performs the same workflow using:

* TFBertModel
* BertTokenizer
* TensorFlow tensors

It demonstrates how pretrained Transformer models can be integrated into TensorFlow-based NLP applications.

---

# 🏗️ Transformer Encoder Architecture

The encoder follows the standard Transformer design:

```text
Input
   │
   ▼
Multi-Head Self Attention
   │
Residual Connection
   │
Layer Normalization
   │
Feed Forward Network
   │
Residual Connection
   │
Layer Normalization
   │
Output
```

# 📊 Expected Output

Example output:

```text

```

or

```text
Hidden States Shape:
(1, 10, 768)
```

where:

* **1** → Batch size
* **10** → Number of tokens
* **768** → Hidden embedding dimension used by BERT Base
